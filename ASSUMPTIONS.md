# Журнал допущений

Каждое решение, способное повлиять на результат, имеет идентификатор, и тот же идентификатор стоит в комментарии к коду. Для каждого пункта указано, где в отчёте показана чувствительность.

## Данные

| ID | Решение | Почему | Альтернатива / чувствительность |
|---|---|---|---|
| A-DATA-WIOD | WIOD 2016 не используется | dataverse.nl отвечает автоматическим запросам страницей «BotStopper: Access Denied»; обходить защиту не стали | Замена: Eurostat FIGARO (межстрановые IO 2010–2024, 50 стран, 64 отрасли) + OECD National Accounts (Table 6/7) + OECD TiMBC + BEA |
| A-DATA-TUR | Турция исключена | в OECD нет Table 7 (занятость, часы) для TUR (HTTP 404) | — |
| A-HOURS | Часы = занятые (OECD Table 7, лица) × часы на занятого. Часы на занятого берутся на самом детальном уровне, где они правдоподобны (900–3300 ч/год); иначе по разделу ISIC, иначе национальное среднее. Итог нормируется на национальные часы | Часы в Table 7 по Мексике сгруппированы иначе, чем занятость (например, у «L» 7400 ч на человека); у США часы есть только для наёмных | Отдельной проверки нет; внутри раздела часы на занятого различаются умеренно |
| A-MERGE | США (FIGARO): C21→C20, J61→J59_60, M71–M73→M74_75, N78–N79→N80-82, R93→R90-92, S95–S96→S94, A03→A02 объединены | Table 7 USA не даёт занятых по этим отраслям: они учтены в «поглотителе» (например, у M74_75 6,5 млн занятых и 35 ч на тыс. евро) | Объединение, а не выдуманное распределение; для США 52 отрасли вместо 63 |
| A-EXCL-BASE | T (домохозяйства как работодатели) и U (экстерриториальные организации) исключены из всех метрик, но остаются в системе IO | нет рыночного выпуска (у T выпуск = зарплата прислуги) или нет выпуска вовсе | — |
| A-ROBUST | Устойчивость: (1) без B, K64–K66, L (добыча, финансы, недвижимость, включая условную ренту); (2) без O84, P85, Q86, Q87_88 (государство); (3) без обоих («core») | Требование задания, этап 5.5 | Во всех таблицах есть подвыборки `all`, `no_rent_fin_mining`, `no_gov`, `core` |
| A-TAX | Чистые налоги на продукты и производство и поправки на покупки резидентов за рубежом (OP_RES/OP_NRES) считаются частью добавленной стоимости, которую должен объяснить базис | Таблицы FIGARO даны в основных ценах, и налоги не относятся ни к труду, ни к ресурсам | Одинаково для всех базисов, поэтому на сравнение не влияет |
| A-PRICE | Индекс цен выпуска: OECD Table 6, P1, PRICE_BASE=DR (цепной дефлятор). Для объединённых отраслей — средний индекс, взвешенный по выпуску | нет физических объёмов | Используется только в динамических тестах |

## Модель

| ID | Решение | Почему | Чувствительность |
|---|---|---|---|
| A-UNIT | Единица продукта = 1 евро (доллар) выпуска в основных ценах. Рыночная цена = 1, поэтому z_j = стоимость/цена | стандарт для IO-таблиц в деньгах | Все метрики построены на отношениях z; значение имеют только масштабно-инвариантные метрики |
| A-NORM | Нормировка Σ z_j x_j = Σ x_j (совокупная стоимость = совокупная цена валового выпуска) на оцениваемой подвыборке | как у Очоа, Шейха, Мариолиса–Цулфидиса | CV, log-SD и d-метрика от нормировки не зависят |
| A-IMP | Импорт (а) по цене: импортные затраты — отдельный непроизводимый ресурс, вертикально интегрированный и оценённый по цене 1; (б) «конкурентный»: импорт считается произведённым внутри страны (A+Aᵐ); (в) MRIO: по содержанию труда или ресурса в стране-экспортёре (полная мировая матрица FIGARO) | задание, этап 3.1 | Все три варианта; раздел «Импорт» отчёта |
| A-CAP-1 | D = b·d′: амортизация на единицу выпуска d_j (OECD P51C/P1) распределена по поставщикам пропорционально структуре валового накопления основного капитала всей экономики (b, отдельно отечественная и импортная часть) | матриц потоков капитала по отраслям в открытом доступе нет | Варианты с капиталом и без; результаты сильно зависят от этого выбора (см. отчёт) |
| A-CAP-MEX | Мексика: CFC по отраслям нет (в Table 6 B2A3N = B2A3G). Берутся отношения CFC/GOS по отраслям США за тот же год и применяются к мексиканскому GOS | единственный доступный прокси | Для Мексики результаты с капиталом менее надёжны; без капитала допущение не нужно |
| A-LI | Трудовой доход = D1 / доля наёмных (самозанятым приписывается средняя оплата наёмных в отрасли), но не больше VA − CFC | стандартная поправка на смешанный доход | Используется в ценах производства, во взвешивании (б) и в замкнутой системе |
| A-RED (а) | «Часы» — неоднородные часы без весов | — | основной вариант |
| A-RED (б) | «Взвешенные по зарплате»: часы × (трудовой доход в час по отрасли / средний) = трудовой доход / (средняя ставка × выпуск). **Потенциально круговой вариант** | так делают многие работы (Zachariah 2006, Fröhlich, Tsoulfidis–Rieu) | показывается отдельно и помечается |
| A-EDU (в) | Веса по образованию (OECD TiMBC, доли ISCED 0–2/3–4/5–8 по 17 агрегатам отраслей; для лет вне 2008–2022 берётся ближайший год). `edu_train`: κ = 1 + (S−9)/40 (дополнительные годы обучения, амортизированные за 40 лет трудовой жизни); `edu_years`: κ = S/9. S = 9; 12,5; 16,5 лет | не используют зарплаты, поэтому не круговые | два варианта |
| A-CLOSE | Замкнутая система: к n товарам добавлено n «видов труда» (труд в отрасли j). Час труда j требует потребительской корзины домохозяйств стоимостью в его фактическую часовую оплату (`closed=True`). Все базисы, включая труд, считаются одной функцией: строки базиса становятся первичными, а всё остальное, в том числе рабочая сила, «производится» | ответ на вопрос о симметрии (п. 1 уточнения). Фактические ставки вносят в товарные базисы информацию о межотраслевых различиях в зарплатах, поэтому добавлен вариант A-CLOSE-U | Трудовой базис в замкнутой системе совпадает с открытым (проверено тестом) |
| A-CLOSE-U | Замыкание с **единой** корзиной на час = s × средняя часовая оплата (`closed="uniform"`); s ≤ 1 — наибольшее значение, при котором ρ ≤ 0,995. Во всех страно-годах s = 1 (ρ ≤ 0,94), то есть корзина равна средней оплате | убирает из товарных базисов информацию о межотраслевых различиях в зарплатах; основной симметричный вариант | сравнение с A-CLOSE во всех таблицах |
| A-RMAX | Если фактическая норма прибыли больше или равна 0,99·R (максимальной в выбранной системе), цены производства считаются при 0,99·R, и это фиксируется в `build_info_*.json` (`r_capped`) | иначе цены производства не существуют (Мексика: r_act = 0,84 при R = 0,77 без капитала и с «конкурентным» импортом) | Флаг в выходных данных |
| A-PP | Цены производства: p = (1+r)(pM + Mᵐ) + w·l, импорт по цене 1, заработная плата выплачивается post factum; r — фактическая норма прибыли на поток нетрудовых затрат (с амортизацией, если учтён капитал). `pp_uniform_wage`: единая часовая ставка; `pp_actual_wage`: фактические отраслевые зарплаты (сраффианская цена издержек с данными различиями в оплате); `pp_eigen`: зарплата авансируется как корзина, p — левый собственный вектор Перрона–Фробениуса матрицы M + b·w′, а r определяется реальной зарплатой | этап 3.4 | Запасов капитала и времени оборота нет, поэтому r считается по потоку, а не по запасу, как у Шейха и Очоа (см. обзор) |
| A-PLAC | Плацебо: 200 случайных «первичных ресурсов» с лог-нормальными коэффициентами того же лог-разброса, что и прямые часы, плюс 50 случайных перестановок вектора часов между отраслями | прямой тест утверждения Климана (2002), что стоимости «не лучше любой случайной переменной с тем же распределением» | распределения в каждой таблице |
| A-BEA-IxI | BEA: матрица «отрасль × отрасль» = D·U/g (допущение о технологии отрасли), D — матрица долей рынка из таблицы Make | стандарт | — |
| A-BEA-L | BEA: труд = FTE наёмных (NIPA 6.5D) × (1 + самозанятые/наёмные, OECD Table 7 USA, по соответствию ISIC). Часы на FTE одинаковы во всех отраслях | таблицы часов 6.9D нет в плоских файлах NIPA; BLS отвечает 403 | Уровень не важен; межотраслевые различия в часах на FTE теряются |
| A-BEA-MERGE | BEA: HS+ORE (жильё, включая условную ренту, + прочая недвижимость) и GFGD+GFGN объединены | у HS нет занятых; FTE по федеральному правительству даны одним рядом | — |
| A-BEA-NEG | BEA: мелкие отрицательные коэффициенты (продажи лома, |a| ≤ 0,003) обнулены, VA уменьшена на ту же сумму | неотрицательность (I−A)⁻¹ | — |
| A-MRIO | В MRIO везде используются занятые (лица, OECD TiMBC), а не часы. Страны без TiMBC и «остальной мир» получают средние коэффициенты незападных стран FIGARO (BR, CN, IN, ID, AR, RU, SA) | согласованные единицы | Сравнивается с национальным расчётом на том же векторе занятых |
