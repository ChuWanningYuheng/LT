# Итерация 13б, этап Д: доступность данных (загрузка без расчётов)

* Скрипт загрузки — `src/lts/v13b/download.py`. Каждая попытка, в том числе неудачная, записана в `data/raw/v13b/attempts.jsonl` (URL, код ответа или ошибка).
* Файлы — в `data/raw/v13b/<источник>/` (каталог `data/raw` в git не входит). Файлы больше 100 МБ — вне репозитория, в `../LT_external/v13b/<источник>/`.
* В `data/raw/MANIFEST.csv` (группа `v13b`) у каждого файла есть URL, размер, sha256 и время загрузки.
* Заголовок запросов: `User-Agent: LT-research-script/1.0 (noreply@anthropic.com)`. Сайты, которые отказывают скриптам (HTTP 403 с уведомлением о ботах), не обходились: User-Agent не подменялся.
* **Расчётов на этих данных не делалось.** Ниже — только метаданные: имена листов и файлов, годы покрытия. При проверке формата на экран попали первые строки файла EIA (цены нефти 1949–1954 гг.); других значений не смотрели.

## Что нужно от пользователя

1. **CPS (приоритет 1 — без них этапы 0.1–0.4 и весь этап 1 невозможны).** Варианты:
   * зарегистрироваться в IPUMS (бесплатно) и добавить ключ в переменную окружения `IPUMS_API_KEY` в настройках облачного окружения; новая сессия его увидит;
   * или скачать вручную файлы NBER March CPS (с 1962 г.) и MORG (с 1979 г.) — либо выгрузки IPUMS CPS — и положить их в папку Google Drive проекта.
2. **Переписи и ACS:** с ключом IPUMS — выгрузки IPUMS USA по нужным переменным. Без ключа — ACS через API Census по выбранным переменным (2005–) или отказ от «больших ячеек» с записью в журнал.
3. **EPI, оплата CEO с 1965 г.:** сайт отказывает скриптам. Можно скачать данные со страницы EPI вручную и положить на Google Drive. Иначе исход 138 считается только по варианту Frydman–Saks (рис. 4: оплата по размеру фирм, агрегированно).
