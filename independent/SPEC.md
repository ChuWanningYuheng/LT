## Входные данные

`data/primitives/{USA,DEU,MEX}_{2010..2023}.npz` — одна страна, один год, n отраслей (объединённые отрасли имеют метки вида `A+B`). Денежные величины — млн евро в текущих ценах.

| Ключ | Размер | Смысл |
|---|---|---|
| labels | n | метки отраслей (NACE, как в FIGARO) |
| Zdom | n×n | промежуточные затраты отечественной продукции: строка = поставщик i, столбец = потребитель j |
| Zimp | n×n | то же для импортной продукции (все страны происхождения) |
| x | n | валовой выпуск |
| hours | n | отработанные часы (все занятые) |
| D1 | n | оплата труда наёмных |
| labour_income | n | трудовой доход (D1 + условный доход самозанятых) |
| cfc | n | потребление основного капитала |
| gfcf_dom, gfcf_imp | n | валовое накопление основного капитала: отечественная и импортная продукция по поставщику |
| hh_dom, hh_imp | n | конечное потребление домохозяйств: отечественная и импортная продукция |
| va | n | добавленная стоимость (все компоненты) |

## Модель

Единица продукта j — 1 евро выпуска, поэтому рыночная цена = 1.

**Коэффициенты.** A = Zdom / x (по столбцам), Aᵐ = Zimp / x. Прямые часы h_j = hours_j / x_j.

**Капитал** (спецификации «с капиталом» и «без»):
- d_j = cfc_j / x_j;
- b_dom = gfcf_dom / G, b_imp = gfcf_imp / G, где G = Σgfcf_dom + Σgfcf_imp;
- с капиталом: M = A + b_dom·dᵀ, Mᵐ = Aᵐ + b_imp·dᵀ; без капитала: M = A, Mᵐ = Aᵐ.

**Импорт — «по цене».** Импортные затраты — непроизводимый ресурс, оценённый по цене 1.

**Базис** — это множество первичных ресурсов P с прямыми затратами a (вектор длины n) и «системой производства» S (матрица n×n). Содержание базиса λ = a·(I − S)⁻¹. Импортное содержание μ = (1ᵀMᵐ_S)·(I − S)⁻¹, где Mᵐ_S — матрица импортных затрат этой же системы. Отношение «стоимость/цена»: z = e·λ + μ, где скаляр e выбран так, что Σ_j z_j x_j = Σ_j x_j.

**Открытая система.**
- Труд: a = h, S = M.
- Товарный базис k (для каждого k, у которого строка k матрицы M имеет положительную сумму): a = M[k,:], S = M с обнулённой строкой k (товар k считается непроизводимым), Mᵐ_S = Mᵐ.

**Замкнутая система (рабочая сила производится).** Здесь реализуйте её **в «свёрнутой» форме**: зарплатные товары добавляются прямо в столбцы товаров.
- β_dom = hh_dom / C, β_imp = hh_imp / C, где C = Σhh_dom + Σhh_imp.
- Вариант «фактические зарплаты»: ω_j = labour_income_j / x_j (денежная оплата на единицу выпуска j).
- Вариант «единая ставка»: ω_j = w̄·h_j, где w̄ = Σ labour_income / Σ hours.
- Mc = M + β_dom·ωᵀ, Mcᵐ = Mᵐ + β_imp·ωᵀ.
- Товарный базис k: a = Mc[k,:], S = Mc с обнулённой строкой k, импорт считается по Mcᵐ.
- Труд в замкнутой системе: a = h, S = M, импорт — по Mᵐ. Обоснуйте в README, почему это совпадает с трудом в «развёрнутой» системе, где n видов труда — отдельные товары, а строки труда первичны.

## Метрики

Оценивается подвыборка: все отрасли, кроме тех, у которых среди частей метки (разделитель `+`) есть `T` или `U`. Ограничьтесь отраслями с x > 0 и конечными z > 0. На подвыборке нормировка повторяется: z ← z·Σx / Σ(z·x). Далее w = x / Σx, q = 1/z.

- MAWD = Σ w_j |q_j − 1|.
- d = √(2·(1 − cos θ)), где θ — угол между q и вектором единиц.

**Процентиль труда** для страны, года и спецификации — доля товарных базисов, у которых метрика строго меньше, чем у труда.
