# Разложение симметричных стоимостей: v_X^sym = O_X + L_X

## Постановка

- n отраслей; M — матрица затрат отечественных продуктов (с капиталом M = A + D), Mᵐ — импортных.
- h — прямые часы на единицу выпуска (вектор-столбец); v = hᵀ(I − M)⁻¹ — стандартные трудовые стоимости.
- b, bᵐ — отечественная и импортная корзины на час труда (денежные единицы каждого продукта на час).

**Расширенная система** (отрасли плюс рабочая сила как сектор). Рабочая сила — производимый «товар» со столбцом затрат (b; 0), который сама ничего не выпускает для отраслей, кроме строки часов hᵀ:

```
A⁺ = | M   b |        A⁺ᵐ = | Mᵐ  bᵐ |
     | hᵀ  0 |              | 0   0  |
```

Исключаем сектор рабочей силы — это точное преобразование: рабочая сила используется только отраслями через hᵀ, а сама потребляет только b. Получается свёрнутая матрица

```
Mc = M + b·hᵀ,     Mcᵐ = Mᵐ + bᵐ·hᵀ.
```

Товары в расширенной системе содержат столько же X, сколько в свёрнутой. Свёрнутая форма — это и есть «замкнутая система с единой ставкой» итерации 1 (независимая реализация этапа 1.1 использует именно её и совпадает с развёрнутой).

**Базис X = товар k.** Строка k становится первичной (k не производится):

```
λ_X = Mc[k,:] · (I − Mc₍ₖ₎)⁻¹,
```

где Mc₍ₖ₎ — Mc с обнулённой строкой k.

## Вывод

Обнулить строку k у Mc = M + b·hᵀ — то же самое, что обнулить строку k у M и элемент k у b:

```
Mc₍ₖ₎ = M₍ₖ₎ + b₍ₖ₎·hᵀ,        b₍ₖ₎ = b с b_k := 0,
Mc[k,:] = M[k,:] + b_k·hᵀ.
```

Обозначения:

```
L_k   = (I − M₍ₖ₎)⁻¹                       — «открытый» леонтьевский обратный с первичным k,
O_X   = M[k,:]·L_k                          — собственное содержание X (асимметричная постановка),
v₍ₖ₎  = hᵀ·L_k                              — трудовые стоимости, если X считать непроизводимым
                                              (без труда, затраченного на производство самого X),
φ     = hᵀ·L_k·b₍ₖ₎ = v₍ₖ₎·b₍ₖ₎            — часы, воплощённые в не-X части корзины на час труда.
```

По формуле Шермана–Моррисона (обращение ранг-1 модификации), при φ < 1:

```
(I − M₍ₖ₎ − b₍ₖ₎hᵀ)⁻¹ = L_k + L_k·b₍ₖ₎·hᵀ·L_k / (1 − φ).
```

Подставляем:

```
λ_X = (M[k,:] + b_k·hᵀ)·[L_k + L_k b₍ₖ₎ hᵀ L_k / (1 − φ)]
    = O_X + (O_X·b₍ₖ₎)·v₍ₖ₎/(1 − φ) + b_k·v₍ₖ₎ + b_k·φ·v₍ₖ₎/(1 − φ)
    = O_X + θ_X · v₍ₖ₎,
```

где

```
θ_X = (b_k + O_X·b₍ₖ₎) / (1 − φ).
```

**Смысл θ_X — полное содержание X в корзине на час труда:**
- b_k — X, который рабочие покупают прямо;
- O_X·b₍ₖ₎ — X, воплощённый в остальных благах корзины;
- 1/(1 − φ) — эффект «круга»: на производство корзины идёт труд, которому тоже нужна корзина.

Итог:

```
v_X^sym = O_X + L_X,        L_X = θ_X · v₍ₖ₎,
```

то есть симметричная X-стоимость = собственное содержание X + θ_X × (трудовые стоимости без X как затраты).

**Импорт (импорт по цене).** μ = 1ᵀMcᵐ(I − Mc₍ₖ₎)⁻¹. Та же выкладка даёт

```
μ = μ_O + θᵐ·v₍ₖ₎,   μ_O = 1ᵀMᵐ·L_k,   θᵐ = (Σbᵐ + μ_O·b₍ₖ₎)/(1 − φ).
```

Отношение «стоимость/цена» z = e·λ + μ (e — нормировочный скаляр) раскладывается точно:

```
z = z_O + z_L,   z_O = e·O_X + μ_O,   z_L = (e·θ_X + θᵐ)·v₍ₖ₎.
```

**Для оценки частей по отдельности** используются стандартные конструкции:
- «O_X в одиночку» — открытый (асимметричный) базис X: z = e′·O_X + μ_O с собственной нормировкой;
- «L_X в одиночку» — трудовые стоимости без X: z = e″·v₍ₖ₎ + 1ᵀMᵐ L_k (масштаб при масштабно-инвариантных метриках не важен).

**Доля трудовой части:** s_L,j = θ_X·v₍ₖ₎,j / λ_X,j (без импорта). Сводки — среднее, взвешенное по выпуску (Σx·θv / Σx·λ), и медиана по отраслям.

**Проверки:**
1. O_X + θ_X·v₍ₖ₎ совпадает с λ_X, посчитанным прямым обращением Mc₍ₖ₎, с точностью до машинного нуля.
2. φ < 1 (иначе ряд расходится; эквивалентно продуктивности замкнутой системы без X).
3. v₍ₖ₎ сравнивается с v: корреляция и максимальное относительное отклонение.
