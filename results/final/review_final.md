Прочитаны REPORT_FINAL, SUMMARY, FINAL_numbers_check, `src/lts/final/check_numbers.py`, REPORT/v2/v3/v4, предрегистрации v2–v4 с журналами, файлы `results/`. `python -m lts.final.check_numbers` запущен: 112 чисел, 0 расхождений (файл сверки перегенерирован без изменений). Все значения, названные ниже «пересчитано», получены мной напрямую из CSV. Сверено 60+ меток [N…] с формулировками текста и 20+ чисел без меток.

Серьёзность: **критично** — меняет статус главного вывода или делает его формулировку неверной; **существенно** — неверное число или описание, отсутствующая оговорка, которая меняет прочтение; **мелко** — точность и редактура.

## Критично

**1. §1, строка 5; §4.4; §7, звено 4 — «цены производства ближе к ценам, чем стоимости: установлено в уровнях».**
*Проблема.* Сам отчёт (§1 «Главное ограничение», §4.2, §6.1) говорит, что метрики уровней вознаграждают малый разброс. К ценам производства он эту проверку не применяет. А ЦП — это часы плюс почти пропорциональная выпуску наценка, то есть вектор ровнее часов.
*Данные* (`results/final/benchmarks_flat_power.csv` против `results/report_tables.md`, MAWD, все отрасли; спецификации v1 и v3 по часам расходятся ≤ 0,002, кроме JPN):
* слепое сжатие часов l^0,5 лучше ЦП с единой ставкой во **всех 13** странах. Например: DEU 0,098 против 0,113 (v2: 0,126); USA 0,180 против 0,200 (v2: 0,226); AUT 0,087 против 0,108;
* плоский вектор лучше ЦП с единой ставкой в ESP, GBR, MEX, POL, USA (у FRA ничья);
* плоский вектор лучше ЦП с фактическими зарплатами в USA (0,114 против 0,127) и GBR (0,123 против 0,134);
* l^0,5 лучше ЦП с фактическими зарплатами в ESP, POL, MEX.

*Вывод.* Превосходство ЦП(б) над стоимостями по уровням нельзя отличить от сжатия разброса. Превосходство ЦП(а) отчёт сам называет «близким к учётным тождествам».
*Исправление.* Статус «установлено» → «частично» (ЦП(а)) и «неразличимо от сжатия разброса» (ЦП(б)). Добавить сравнение ЦП с плоским вектором и l^α в §4.4. Убрать «(установлено)» из §7, звено 4. Хорошо бы сравнить ЦП и часы при равном разбросе, как в Б0б.

**2. §1, строка 8; §4.7; §7, звено 5; SUMMARY, п. 8 — «отрицательная связь есть только без контролей… исчезает при контролях и инструментах, создаётся ловушками измерения».**
*Проблема.* Текст сильнее данных.
*Данные* (`results/v4/b31.csv`):
* инструмент «другие страны» даёт ту же точечную оценку, β = −0,0286 против −0,0284; растёт только SE (0,023 против 0,012). Это потеря точности, а не исчезновение связи;
* инструмент «лаг 2 года»: β = −0,028, **p = 0,026** — в отчёте не упомянут;
* с отраслями ренты **и с контролями**: β = −0,046, **p = 0,005**. Значит, фраза «только без контролей» неверна;
* только материальный капитал: −0,045, p < 0,001;
* без поправки на смешанный доход, с контролями: −0,052, p < 0,001;
* амортизация вместо запаса, с контролями: −0,130, p = 0,018.

Первичная спецификация уже включает поправку на смешанный доход и остаётся значимой после Холма. Значит, «создаётся ловушками» не следует из данных: поправка ослабляет связь, но не устраняет её.

Связь исчезает в двух местах. Первое — первичная спецификация с контролями, где выборка сокращается с 12 595 до 10 848 наблюдений (этого в тексте нет), а контроль PCM = Π/GO имеет общий числитель с r; без него знак меняется (разведочно). Второе — вариант с нематериальными активами (−0,017, p = 0,15).

*Исправление.* Статус «не подтверждено» по правилу (М требует значимости во всех проверках) верен, его можно оставить. Формулировку заменить на «знак Маркса есть в большинстве спецификаций (перечислить); значимость неустойчива: пропадает с контролем PCM (плохой контроль, механически связанный с r) и при учёте нематериальных активов». Указать смену выборки при контролях. Убрать «исчезает при инструментах» и «создаётся ловушками».

29. **Смешение спецификаций.** В одном рассуждении стоят MAWD часов DEU 0,158 (спецификация ит. 1) и 0,160 (спецификация v3, файл плоского эталона). Для ЦП с единой ставкой есть два числа: DEU 0,113 (ит. 1) и 0,126 (v2). Надо указать, какая спецификация где.
30. **SUMMARY.** Раздел «Что установлено» содержит пункты со статусами «неразличимо» и «не подтверждено»; лучше назвать «Главные результаты». В п. 7 пропущено «и 95% перестановок».
